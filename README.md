# 💄 Soniya Patange Makeups

An ultra-premium modern makeup artist portfolio and booking website built with React and modern frontend technologies.

This project was designed to showcase makeup services, portfolio galleries, client experience, and online booking functionality with a luxurious and responsive UI/UX.

---

# ✨ Features

- Ultra Premium Modern UI/UX
- Fully Responsive Design
- Beautiful Animations & Transitions
- Makeup Portfolio Showcase
- Services Section
- Client Testimonials
- Online Booking System
- WhatsApp Integration
- Contact & Inquiry Forms
- Fast Loading Performance
- SEO Friendly Structure
- Mobile Optimized Experience
- Elegant Gallery Layouts
- Smooth Scroll Experience
- Reusable Component Architecture

---
